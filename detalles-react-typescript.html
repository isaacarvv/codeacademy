React y TypeScript Essentials

TypeScript hace que tus componentes React comuniquen mejor qué datos necesitan y qué valores pueden devolver.

Describe las props

Las props son los datos que un componente recibe desde su padre. Define un tipo para documentar y verificar esas entradas antes de ejecutar la aplicación.

  • Los tipos detectan errores antes de llegar al navegador.
  • Las props opcionales se marcan con ?.
  • Los nombres precisos mejoran el autocompletado del editor.

Un componente tipado

Este ejemplo recibe un nombre y muestra una tarjeta simple. Si falta la prop obligatoria, TypeScript avisará.

// Saludo.tsx
type SaludoProps = {
  nombre: string;
  activo?: boolean;
};

export function Saludo({ nombre, activo = true }: SaludoProps) {
  return <p>{activo ? `Hola, ${nombre}` : 'Sin conexión'}</p>;
}
Idea clave

No necesitas tipar todo explícitamente. Empieza por las props, las respuestas de API y las funciones públicas: son los límites donde más valor aporta TypeScript.
