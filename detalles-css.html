CSS Grid y Flexbox Pro

Los sistemas de layout modernos te permiten ordenar contenido de forma flexible, consistente y adaptable a cualquier pantalla.

Cuándo usar Flexbox

Flexbox es ideal para distribuir elementos en una sola dirección: una fila o una columna. Piensa en una barra de navegación, un grupo de botones o una tarjeta.

  • Usa display: flex para activar el contexto flexible.
  • Controla la alineación con justify-content y align-items.
  • Permite que los elementos se adapten usando flex-wrap.

Una cuadrícula adaptable

CSS Grid trabaja en dos dimensiones y es perfecto para galerías, dashboards y secciones de tarjetas.

/* tarjetas.css */
.grid-cursos {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1.25rem;
}

Diseña primero para todas las pantallas

Las media queries ajustan el layout cuando el espacio cambia. Comienza con una columna y agrega complejidad solo cuando exista espacio suficiente.

@media (min-width: 768px) {
  .grid-cursos { grid-template-columns: repeat(3, 1fr); }
}

Crea una escala de espaciado

Repetir los mismos valores de separación hace que una interfaz se sienta coherente. Define variables para los espacios más usados.

:root {
  --espacio-1: 0.5rem;
  --espacio-2: 1rem;
  --espacio-3: 1.5rem;
}

Construye tarjetas reutilizables

Una tarjeta combina espaciado interno, borde sutil y una jerarquía tipográfica clara. Evita sombras demasiado fuertes para mantener el contenido legible.

.tarjeta {
  padding: 1.25rem;
  border: 1px solid #30363d;
  border-radius: 0.75rem;
}
Idea clave

El patrón auto-fit con minmax() crea columnas responsivas sin escribir media queries adicionales.

PRACTICA

Diseña una cuadrícula

Prueba cambiar el tamaño mínimo de las columnas y observa cómo afectaría el layout.
