Master en Next.js 14

Next.js te permite crear aplicaciones web rápidas con React, renderizado en el servidor y rutas basadas en archivos.

El App Router

En Next.js 14, cada carpeta dentro de app puede representar una ruta. El archivo page.tsx define lo que se muestra cuando una persona visita esa dirección.

  • Las rutas se organizan con carpetas, sin configuración extra.
  • Los layouts permiten compartir navegación y estructura.
  • Los componentes se renderizan en el servidor por defecto.

Una página inicial

Esta es una página mínima usando el App Router. Observa que no necesitas importar React para escribir JSX.

// app/page.tsx
export default function Inicio() {
  return (
    <main>
      <h1>Hola desde Next.js</h1>
      <p>Mi primera ruta con App Router.</p>
    </main>
  );
}
Idea clave

Un Server Component puede obtener datos de forma segura antes de enviar HTML al navegador. Añade 'use client' solo cuando necesites interacción del usuario.
