La estructura de un documento HTML

Antes de añadir estilos o interactividad, todo sitio web necesita una base clara. HTML define la estructura y el significado del contenido que verá el navegador.

¿Qué encontrarás en un documento HTML?

Un documento HTML moderno comienza indicando su tipo, contiene una zona de configuración llamada head y una zona visible llamada body. Cada una tiene responsabilidades distintas.

  • DOCTYPE: informa al navegador que trabajamos con HTML5.
  • Head: reúne metadatos, el título y enlaces a recursos como CSS.
  • Body: contiene todo lo que las personas pueden leer e interactuar.

Tu primera estructura

Observa esta plantilla. No necesitas memorizarla de inmediato: úsala como punto de partida para tus proyectos y entenderás cada parte mientras practicas.

<!-- index.html -->
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>Hola, mundo</h1>
    <p>Estoy aprendiendo desarrollo web.</p>
  </body>
</html>

La propiedad lang="es" ayuda a lectores de pantalla y motores de búsqueda a identificar el idioma principal. Es un pequeño detalle con un impacto importante en accesibilidad.

Consejo de práctica

Crea un archivo llamado index.html, copia la estructura y ábrelo en tu navegador. Cambia el título y el texto para hacerlo tuyo.
