HTML Semántico y Accesible

HTML semántico describe el significado del contenido. Es la base para interfaces más claras, accesibles y fáciles de mantener.

Usa landmarks para estructurar

Las etiquetas semánticas crean puntos de referencia que ayudan a las personas y a las tecnologías asistivas a recorrer la página.

  • header presenta la cabecera de una página o sección.
  • main contiene el contenido principal y debe aparecer una sola vez.
  • nav, article, aside y footer explican el propósito de cada bloque.

Mantén una jerarquía lógica

Los encabezados no se eligen por tamaño visual. Representan niveles de contenido, desde el título principal hasta las subsecciones.

<!-- estructura semántica -->
<main>
  <article>
    <h1>Guía de accesibilidad</h1>
    <section>
      <h2>Navegación por teclado</h2>
      <p>Todo control debe ser alcanzable.</p>
    </section>
  </article>
</main>
Idea clave

Antes de añadir ARIA, utiliza primero el elemento HTML nativo que describe correctamente lo que necesitas. La semántica nativa suele ser más robusta.

PRACTICA

Convierte un bloque en una página semántica

Reemplaza los div por elementos que describan el contenido.
