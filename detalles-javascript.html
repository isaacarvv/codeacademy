JavaScript desde Cero

JavaScript añade comportamiento a tus páginas. Con él puedes responder a clics, transformar datos y construir experiencias interactivas.

Guarda información con variables

Una variable es un nombre que apunta a un valor. Usa const cuando no cambiará y let cuando sí necesitas actualizarlo.

  • const: crea referencias que no se reasignan.
  • let: permite actualizar el valor más adelante.
  • Elige nombres claros que expliquen su propósito.

Agrupa instrucciones con funciones

Las funciones evitan repetir código. Reciben datos, realizan una tarea y pueden devolver un resultado.

// saludo.js
const saludar = (nombre) => {
  return `Hola, ${nombre}. ¡A programar!`;
};

const mensaje = saludar('Ada');
console.log(mensaje);
Idea clave

Una función debe hacer una cosa concreta. Cuando su nombre explica la acción, tu código se vuelve más fácil de leer y mantener.
